# 🤖 Telegram Channel Sentinel Bot (គាំទ្រភាសាខ្មែរ & English)

Bot Telegram សម្រាប់គ្រប់គ្រងឆានែលស្វ័យប្រវត្តិកម្រិតខ្ពស់ Auto-Ban អ្នកចាកចេញតាមកម្រិតកំណត់ (១ ឆ្នាំ, ៣ ខែ, ១ ខែ, រហូត...) ស្កេនសមាជិកចាស់វស្សា ២០ នាក់ដំបូង របាយការណ៍សកម្មភាពប្រចាំថ្ងៃ និងមានប៊ូតុងម៉ឺនុយប៉ះងាយស្រួលប្រើបំផុតនៅលើទូរស័ព្ទ។

---

## 🇰🇭 មុខងារពិសេសៗ (Features in Khmer)

### 1. 🎯 ច្បាប់ Auto-Ban ឆ្លាតវៃតាមកម្រិត (Dynamic Tiered Ban):
គណនាចំនួនថ្ងៃដែលសមាជិកស្នាក់នៅមុនពេលចាកចេញដោយស្វ័យប្រវត្តិ៖
- **ចូលថ្ងៃនេះ & ចាកចេញ (< ១ ថ្ងៃ):** ➔ **ហាមឃាត់ (Ban) ១ ឆ្នាំ**
- **ស្នាក់នៅ ១ សប្តាហ៍ (១ - ៧ ថ្ងៃ):** ➔ **ហាមឃាត់ ៣ ខែ**
- **ស្នាក់នៅ ១ ខែ (១ - ៤ សប្តាហ៍):** ➔ **ហាមឃាត់ ១ ខែ**
- **ស្នាក់នៅ ៦ ខែ:** ➔ **ហាមឃាត់ ២ សប្តាហ៍**
- **ស្នាក់នៅយូរអង្វែង (> ៦ ខែ):** ➔ **ហាមឃាត់រហូត (Forever)**
*(អ្នកក៏អាចប្តូរទៅ Ban រយៈពេលថេរដូចជា Ban រហូត, ១ ឆ្នាំ, ៣ ខែ, ឬ ១ ខែ បានដោយគ្រាន់តែចុចប៊ូតុងនៅក្នុង `⚙️ ការកំណត់`)*

### 2. 🟢 ប៊ូតុងដោះលែង ១ ចុច (1-Click Unban Button):
រាល់ពេលមានអ្នកចាកចេញ Bot នឹងផ្ញើសារជូនដំណឹងភ្លាមៗជាមួយប៊ូតុង **`[ 🟢 ដោះលែងសមាជិក (Unban) ]`**។ ចុចតែមួយដង Bot នឹងដោះលែងសមាជិកនោះភ្លាម!

### 3. 👑 ស្កេនសមាជិកចាស់វស្សា ២០ នាក់ (Top 20 Members):
ចុចប៊ូតុង **`👑 សមាជិកចាស់ (Top 20)`** ឬវាយ `/scan` ដើម្បីមើលសមាជិកចាស់ និងស្មោះត្រង់បំផុត ២០ នាក់ដំបូង រួមទាំងចំនួនថ្ងៃដែលពួកគេស្នាក់នៅក្នុងឆានែល។

### 4. 📈 របាយការណ៍សកម្មភាពប្រចាំថ្ងៃ (Daily Report):
- **ស្វ័យប្រវត្តិ:** ផ្ញើសេចក្តីសង្ខេបរៀងរាល់ ២៤ ម៉ោងនៅម៉ោង 00:00 UTC។
- **មើលភ្លាមៗ:** ចុចប៊ូតុង **`📊 របាយការណ៍ (Report)`** ដើម្បីមើលចំនួនសមាជិកចូលថ្មី ចាកចេញ Auto-Ban និងកំណើនសុទ្ធថ្ងៃនេះ ឬម្សិលមិញ។

### 5. 📱 ប៊ូតុងម៉ឺនុយ Touch Screen ងាយស្រួលប្រើបំផុត (Easy Mobile Buttons):
នៅពេលបើក Bot វានឹងបង្ហាញផ្ទាំងប៊ូតុងនៅលើក្ដារចុចទូរស័ព្ទរបស់អ្នក៖
```
[ 📊 របាយការណ៍ (Report) ]    [ 👑 សមាជិកចាស់ (Top 20) ]
[ ⚙️ ការកំណត់ (Settings) ]    [ 🔍 ស្វែងរក (Lookup) ]
[ 📦 ទាញយក CSV (Export) ]   [ 🌐 ភាសា / Language ]
```
គ្រាន់តែចុចលើប៊ូតុង មិនបាច់ចាំចំណាំពាក្យបញ្ជា slash (`/`) ឡើយ!

### 6. 🌐 គាំទ្រ ២ ភាសា (Khmer & English):
អាចប្តូររវាង 🇰🇭 **ភាសាខ្មែរ** និង 🇬🇧 **English** បានភ្លាមៗដោយចុចប៊ូតុង `🌐 ភាសា / Language`។

## 🛠️ របៀបដំឡើង និងភ្ជាប់ Bot ទៅកាន់ Telegram Channel

### ជំហានទី ១: បង្កើត Bot យក Token
1. ចូលទៅ Telegram ស្វែងរក [@BotFather](https://t.me/BotFather)។
2. ផ្ញើពាក្យបញ្ជា `/newbot` រួចដាក់ឈ្មោះ និង Username ឱ្យ Bot។
3. ចម្លងយកកូដ **HTTP API Token** (ឧទាហរណ៍៖ `1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ`)។

### ជំហានទី ២: យក Telegram User ID របស់អ្នក
1. ស្វែងរក [@userinfobot](https://t.me/userinfobot) ក្នុង Telegram រួចចុច `/start`។
2. ចម្លងយកលេខសម្គាល់ **Id** របស់អ្នក (ឧទាហរណ៍៖ `123456789`) ដើម្បីធ្វើជា `ADMIN_ID`។

### ជំហានទី ៣: ដាក់ Bot ជា Administrator ក្នុង Channel
1. បើក Telegram Channel របស់អ្នក ➔ ចូលទៅ **Administrators** ➔ **Add Administrator**។
2. ស្វែងរក Username របស់ Bot អ្នក ហើយជ្រើសរើសវា។
3. បើកសិទ្ធិ **"Ban Users"** (ឬ "Restrict Members") ឱ្យទៅជា **ON**។
4. ចុច Save។

> ⚠️ **សំខាន់:** សូមចុច `/start` នៅក្នុងឆាតផ្ទាល់ខ្លួនជាមួយ Bot ដើម្បីឱ្យ Bot មានសិទ្ធិផ្ញើសារដំណឹងទៅកាន់អ្នកបាន!

## 🚂 របៀប Deploy លើ Railway ឱ្យដំណើរការ ២៤/៧

1. Push កូដពី Folder នេះទៅកាន់ GitHub របស់អ្នក៖
   ```bash
   cd C:\Users\TUF\.gemini\antigravity\scratch\telegram-autoban-bot
   git init
   git add .
   git commit -m "Telegram Sentinel Bot with Khmer"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/telegram-autoban-bot.git
   git push -u origin main
   ```
2. ចូលទៅកាន់គេហទំព័រ [Railway.app](https://railway.app/) រួចចុច **New Project** ➔ **Deploy from GitHub repo**។
3. ជ្រើសរើស Repository របស់អ្នក។
4. នៅក្នុងផ្ទាំង **Variables** នៅលើ Railway សូមបន្ថែម៖
   - `BOT_TOKEN`: *Token ទទួលបានពី @BotFather*
   - `ADMIN_ID`: *Telegram ID របស់អ្នក*
   - `DB_PATH`: `/app/data/bot.db`
   - `LOG_CHANNEL_ID`: *(ជម្រើសបន្ថែម ប្រសិនបើចង់ឱ្យផ្ញើទៅ Channel កត់ត្រា)*
5. **ភ្ជាប់ Persistent Volume (សំខាន់បំផុត ដើម្បីកុំឱ្យបាត់ទិន្នន័យ):**
   - នៅលើ Railway ចុច **+ New** ➔ **Volume**។
   - ភ្ជាប់វាទៅកាន់ Bot របស់អ្នក ហើយកំណត់ Mount Path ដាក់៖ `/app/data`
6. Railway នឹង Build តាមរយៈ Dockerfile ដោយស្វ័យប្រវត្តិ ហើយ Bot នឹងដំណើរការ ២៤ ម៉ោងលើ ២៤ ម៉ោង!
